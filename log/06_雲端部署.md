# 06 — 雲端部署（Vercel）

## 為什麼要部署到雲端？

本機開發時，網站只跑在你自己的電腦上（`localhost:3000`）。  
部署到雲端後，任何裝置、任何地方都可以開啟你的 Dashboard。

這個專案部署在 **Vercel**，網址是：  
`https://vibe-leetcode.vercel.app`

---

## Vercel 是什麼？

Vercel 是專門給 Next.js 用的雲端平台（Next.js 的開發公司就是 Vercel）。

好處：
- 和 GitHub 連動：`git push` 就自動重新部署
- 免費方案對個人專案足夠
- 自動 HTTPS、CDN 加速
- 可以設定環境變數（就像本機的 `.env.local`）

---

## 部署流程圖

```
你的電腦
  git push → GitHub Repository
                │
                ▼
           Vercel 偵測到新 commit
                │
                ▼
           Vercel 自動執行：
             npm install
             npm run build
                │
                ▼
           部署完成 → https://vibe-leetcode.vercel.app
```

---

## 第一次部署步驟

### 1. GitHub 建立 Repository
先把程式碼推到 GitHub（需要先在 GitHub 建立一個 Repository）。

### 2. Vercel 連接 GitHub
1. 前往 [vercel.com](https://vercel.com)，用 GitHub 帳號登入
2. 點「New Project」
3. 選你的 GitHub Repository
4. 框架會自動偵測為 Next.js
5. 點「Deploy」

### 3. 設定環境變數（重要！）

本機用 `.env.local` 存放密鑰，但這個檔案不會上傳到 GitHub（在 `.gitignore` 裡）。

Vercel 需要你手動填入這些變數：

**在哪裡設定：**  
Vercel 專案頁面 → 左側選單 **「Environment Variables」**（不是 Settings 裡的子頁面，是左側的獨立選項）

**需要填入的變數：**

| 變數名稱 | 說明 | 範例 |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 專案網址 | `https://abcxyz.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase 匿名金鑰 | `eyJhbGci...` 一長串 |
| `WEBHOOK_SECRET` | Webhook 驗證密碼 | 自訂任意字串 |
| `NEXT_PUBLIC_USE_MOCK` | 是否使用假資料 | `false`（正式環境用真資料）|

**在哪裡找 Supabase 的值：**  
Supabase Dashboard → 專案 → 左側「Settings」→「API」

### 4. 設定完後需要重新部署
改完環境變數後，Vercel 不會自動更新。需要：
1. 前往「Deployments」頁面
2. 點最新的 Deployment 右側三個點
3. 選「Redeploy」

## 本機開發 vs Vercel 環境對比

| | 本機 | Vercel |
|---|---|---|
| 啟動指令 | `npm run dev` | 自動 |
| 環境變數來源 | `.env.local` | Vercel Environments 頁面 |
| 網址 | `localhost:3000` | `https://vibe-leetcode.vercel.app` |
| 更新方式 | 儲存檔案即時更新 | `git push` 後自動重部署 |
| API 網址 | `localhost:3000/api/webhook` | `https://vibe-leetcode.vercel.app/api/webhook` |

## Chrome Extension 要改 Webhook URL

部署到 Vercel 之後，Extension 的 Webhook URL 要從本機改成 Vercel：

1. 點開 Extension 圖示
2. Webhook URL 改成：`https://vibe-leetcode.vercel.app/api/webhook`
3. Secret 填你在 Vercel 設的 `WEBHOOK_SECRET`

## 每次更新程式碼的流程

```bash
# 1. 存檔（VS Code 自動存）
# 2. 把變更提交到 Git
git add .
git commit -m "說明這次改了什麼"

# 3. 推到 GitHub
git push

# Vercel 偵測到 push，自動重新部署（約 1-2 分鐘）
```

## 查看部署狀態

Vercel 專案頁面的「Deployments」頁可以看到：
- 每次 push 的部署記錄
- 部署成功 ✅ 或失敗 ❌
- 點進去可看「Build Logs」——如果部署失敗，錯誤訊息在這裡

---

## 常見問題

### 部署成功但網站顯示空白 / 題庫沒有資料
→ **環境變數沒設定**（最常見原因）  
確認 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_ANON_KEY` 正確填入，然後 Redeploy。

### `NEXT_PUBLIC_USE_MOCK=true` 導致永遠顯示假資料
→ 在 Vercel 把這個變數設為 `false` 或直接刪除。

### Extension 無法同步到 Vercel
→ 確認 Extension 裡的 Webhook URL 是 Vercel 網址（不是 localhost），Secret 和 Vercel 環境變數一致。

### 部署失敗，Build Logs 顯示 TypeScript 錯誤
→ 在本機先跑 `npm run build`，確認沒有錯誤再 push。

## 費用說明

Vercel 免費方案（Hobby）限制：
- 每月 100 GB 頻寬
- 每次部署最多 60 秒 build 時間
- 個人專案完全夠用

Supabase 免費方案限制：
- 500 MB 資料庫空間
- 每月 2 GB 傳輸量
- 超過 7 天無活動可能暫停（重新登入會自動恢復）
