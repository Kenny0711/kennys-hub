# 00 — 這個系統在做什麼？（白話總覽）

## 用一句話說

> 你在 LeetCode 解題 → 系統自動把題目和程式碼存起來 → 你可以在自己的網站上回顧所有解法。

---

## 用比喻來說

想像你是一個廚師，每次做完一道菜，都希望把食譜記錄下來，方便以後複習。

這個系統就像是：

| 比喻 | 實際對應 |
|---|---|
| 廚師做完菜 | 你在 LeetCode 寫完程式碼，按下 Submit |
| 自動拍照記錄食譜 | Chrome Extension 自動擷取你的程式碼和題目資料 |
| 把食譜傳給助理 | Extension 把資料 POST 到 API（用 HTTP 傳資料） |
| 助理把食譜整理後存入食譜本 | API 收到資料，存進 Supabase 資料庫 |
| 你查閱食譜本 | 你打開 Dashboard 網站，看自己的刷題紀錄 |

---

## 系統的四個角色

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  [1] Chrome Extension   →   [2] Next.js API             │
│      住在瀏覽器裡              住在 Vercel 雲端           │
│      負責「擷取資料」          負責「接收資料、驗證、存檔」  │
│                                         │               │
│                                         ↓               │
│  [4] Dashboard          ←   [3] Supabase 資料庫          │
│      住在 Vercel 雲端          住在 Supabase 雲端          │
│      負責「顯示資料」          負責「存放所有資料」          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 角色 1：Chrome Extension（擴充功能）
- 裝在你的 Chrome 瀏覽器上
- 當你在 LeetCode 按 Submit，它會偷偷在背後偵測
- 如果判定是 Accepted（通過），就自動把資料送走
- 也可以手動按按鈕來送出

### 角色 2：Next.js API
- 一個在雲端跑的程式（像是一個接電話的人）
- 收到 Extension 送來的資料後，檢查有沒有帶正確的「密碼」（Secret）
- 把資料整理好，存進資料庫

### 角色 3：Supabase 資料庫
- 真正的儲存空間，有點像 Google 試算表，但更強大
- 每道題目存成一列，包含題號、難度、Tags、程式碼等等

### 角色 4：Dashboard（網站）
- 你看得到的網站，住在 `https://vibe-leetcode.vercel.app`
- 顯示你的刷題統計、題庫列表、每題的解法

## 一次完整的流程（以「自動同步」為例）

```
你在 LeetCode 按下 Submit
        │
        ▼
Extension 的 main_world.ts 攔截到這個提交動作
        │
        ▼
Extension 等待 LeetCode 判題結果...
        │
        ▼  （如果是 Accepted）
Extension 的 content.ts 擷取題目資料
  → 題號、題目名稱、難度、Tags、程式碼、語言
        │
        ▼
把資料交給 background.ts（背景程式）
        │
        ▼
background.ts POST 到 https://vibe-leetcode.vercel.app/api/webhook
  → 帶上 x-webhook-secret: dev-secret（安全驗證）
        │
        ▼
Next.js API（webhook/route.ts）收到資料
  → 驗證 secret ✓
  → 整理程式碼格式
  → 查資料庫有沒有這題
  → 有：加一筆新解法
  → 沒有：建立新題目
        │
        ▼
資料存進 Supabase 的 leetcode_records 表
        │
        ▼
你打開 https://vibe-leetcode.vercel.app
  → 看到新題目出現在題庫裡 ✓
```

## 這個系統用了哪些「雲端服務」

| 服務 | 做什麼 | 費用 |
|---|---|---|
| **Vercel** | 跑你的 Next.js 網站（前端 + API） | 免費（個人用） |
| **Supabase** | 存你的題目資料（資料庫） | 免費（有配額） |
| **GitHub** | 存程式碼、Vercel 自動從這裡部署 | 免費 |

> **重點：** 你不需要自己買伺服器，全部用雲端服務免費跑起來。
